# OnigiriDex 鬼斬 図鑑

Fan-made database for **Onigiri**: dungeons, monsters, drop tables, items, bestiary, magatama dissolution, an exact build planner and a boss simulator.

Made by **Naoyuki**.

Skill data (damage, hit rates, T, CBT, RT, cooldowns, ratings) and the rotation / Weighted DPS rules come from the **Onigiri Skill Database** by **ikzki**.

Site: open `index.html` (served with GitHub Pages).

Data is read from the game files with the game's own engine. Onigiri and all of its names, images and data belong to their respective owners; this is an unofficial fan project.
